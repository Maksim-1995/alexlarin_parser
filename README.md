# Alexlarin Parser

Парсер тренировочных вариантов профильной математики с alexlarin.net.
Проверен на [варианте № 542](https://alexlarin.net/ege/2026/trvar542.html).

Скачивает PDF, извлекает условия заданий 1–19 и изображения,
собирает ответы, формирует Excel и итоговый ZIP.

## Установка и запуск

Команды для Linux выполняются из корня проекта:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

Запуск:

```bash
python main.py --url "https://alexlarin.net/ege/2026/trvar542.html"
```

Вариант 542 используется по умолчанию:

```bash
python main.py
```

Справка:

```bash
python main.py --help
```

## Данные и результат

Исходные HTML, PDF, JavaScript и картинка ответов сохраняются в `input/`.

Результат для варианта 542:

- `output/trvar542/tasks.xlsx` — таблица заданий и метаданные;
- `output/trvar542/images/` — встроенные изображения и снимки заданий;
- `output/trvar542/trvar542_result.zip` — Excel и папка изображений.

Лист `Tasks` содержит колонки:
`task_num`, `condition`, `image_name`, `solution`, `answer`.

В `image_name` записаны имена файлов из папки `images/`,
по одному на строку. Колонка `solution` оставлена пустой.

Лист `about` содержит метаданные и сведения об источнике ответов.
Дата в метаданных — дата формирования выгрузки.

## Ответы и ограничения

Ответы 1–12 извлекаются регулярным выражением из распакованного
JavaScript. Ответы сохраняются строками, включая значения
с десятичной запятой и завершающими нулями.

Ответы 13–19 вручную перенесены из
[опубликованной картинки](https://alexlarin.net/ege/2026/trvar542.png)
в `input/trvar542_answers.json`. Автоматическое распознавание
ответов с картинки пока не реализовано.

Для другого варианта необходим соответствующий файл
`input/<имя PDF>_answers.json`.

При извлечении текста PDF математические формулы могут терять
расположение символов. Для каждого задания сохраняется снимок,
передающий исходный вид условия.

Определение областей заданий и привязка рисунков рассчитаны
на двухколоночную верстку проверенного варианта.

## Тесты

```bash
python -m pytest -q
```

Тесты проверяют многострочные условия, границы заданий,
пропущенные и повторяющиеся номера, сохранение формата ответов
и различие между присваиванием `=` и сравнением `==`.

# Обработка основных вариантов №21–25

Дата начала: 19.11.2026. Объект: пять полных вариантов со всеми задачами.
Поручение пользователя разрешает загрузки и модельную обработку только №21–25.
Применяется навык [implement-parser-task](../.agents/skills/implement-parser-task/SKILL.md),
общий конвейер DeepSeek с thinking классификации disabled.

Перед началом рабочее дерево чистое. Прочитаны инструкции и передача контекста,
README и карта архитектуры. Другие варианты не запускаются; `.env`, CSV,
промпты, исходные кэши и прежние выдачи сохраняются.

План: источники из реальных href, OCR/классификация, полная содержательная
сверка условий/ответов/рисунков/категорий, коррекции с provenance по необходимости,
проверка Excel/ZIP и локального повторного использования кэшей.
Критерий SUCCESS — проверенные результаты без незакрытых замечаний;
отсутствующие опубликованные ответы не дополняются собственным решением.

План CLI подтвердил основные ссылки `https://alexlarin.net/ege/2013/trvar21.html`
и №22–25. Снимок 1564 прежних файлов: `reports/pilot_21_25/before.json`.

```bash

PYTHONDONTWRITEBYTECODE=1 PYTHONPATH=. .venv/bin/python -u reports/pilot_21_25/prepare_sources.py
```

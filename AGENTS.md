# Работа с alexlarin_parser

Перед изменениями прочитай [подробные инструкции](.agents/agents.md) и
[README](README.md). Длинный файл инструкций при необходимости читай частями,
чтобы не потерять конец из-за ограничения вывода.

В `.agents/agents.md` находятся принятые требования заказчика, архитектура,
состояние работ, известные ошибки и порядок передачи контекста в новый чат.
Явные актуальные инструкции пользователя имеют приоритет.

- Отвечай по-русски. Сначала проверь `git status --short`; сохрани чужие правки.
- Реализация находится в `alexlarin_parser/`; корневые модули сохраняют совместимость.
- Для документации и рефакторинга используй проверки без внешних модельных API.
- Gemini, NVIDIA и DeepSeek имеют разные роли; проверь их фактическую интеграцию
  в README. Не объявляй общий выбор провайдера реализованным, пока его нет в коде.
- Не запускай новые варианты, API-проверки или переобработку кэшей без соответствующего
  задания. `--local-only` запрещает скачивания, но не вызовы модели.
- Не изменяй `.env`, готовые архивы и исходные кэши ради проверки структуры.
- Исторические `NEEDS_REVIEW` не являются готовностью к импорту.

Если работа продолжается в новом чате, начни с раздела передачи контекста
в подробных инструкциях и проверь доступность упомянутых локальных отчётов.
